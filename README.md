# Análise de SAC com Power BI

## Sobre o projeto
Projeto de análise de dados de Serviço de Atendimento ao Cliente (SAC), desenvolvido com Power BI utilizando uma base de dados fictícia disponibilizada para fins de aprendizado.

## Objetivo
Analisar indicadores de atendimento, identificar os problemas mais frequentes e acompanhar a evolução do volume e do tempo de atendimento entre 2023 e 2025.

## Indicadores e análises
- Volume total de atendimentos e média diária.
- Tempo médio de atendimento e retorno.
- Percentual de atendimentos cancelados.
- Distribuição dos atendimentos por tipo de problema.
- Volume de atendimentos por agente.
- Evolução mensal dos indicadores.

## Ferramentas
- Microsoft Power BI
- Power Query
- Visualização e análise de dados

## Arquivos
O repositório contém o dashboard exportado em PDF e o modelo do Power BI para consulta, conforme as condições de compartilhamento da base utilizada.

## Aprendizados
Prática na construção de dashboards, organização de indicadores, criação de visualizações e análise exploratória de dados para apoiar a compreensão do desempenho do atendimento.
